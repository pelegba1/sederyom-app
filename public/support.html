תמיכה: סדר יום

משהו לא עובד, או שיש לך שאלה? אפשר לכתוב אל bahatpeleg@gmail.com ונחזור אליך.

איך מחברים את סדר יום לצ׳אט?

  1. מוסיפים את סדר יום בצ׳אט ומתחילים להתחבר. נפתח דף של סדר יום שמבקש קוד.
  2. באפליקציה פותחים הגדרות ← אני ובית הספר ← חיבור לצ׳אט, בוחרים מה לשתף ויוצרים קוד.
  3. מקלידים את הקוד בדף של סדר יום, ומסמנים שמלאו לך 13. לא שולחים את הקוד בצ׳אט.

הקוד לא עובד

קוד תקף לזמן קצר ולשימוש אחד. אם פג תוקפו, יוצרים קוד חדש באפליקציה.

הצ׳אט אומר שהמידע ישן

הטלפון הוא שמעדכן את המידע. פותחים את סדר יום, והעדכון יוצא מעצמו.

איך משנים מה משותף, או מנתקים?

הכול נמצא באפליקציה, במסך ״חיבור לצ׳אט״. ניתוק הצ׳אט האחרון מוחק את העותק שנשמר. עוד פרטים במדיניות הפרטיות ובתנאי השימוש.

Support (English)

Need help? Write to bahatpeleg@gmail.com.

  • Connecting a chat. Add SederYom in the chat and start connecting; a SederYom page opens and asks for a code. In the app, open Settings, then the page about you and your school, then the chat connection, choose what to share and create a code. Type it on the SederYom page and confirm that you are 13 or over. Never send the code in the chat.
  • The code does not work. A code lasts a short time and works once. Create a new one in the app.
  • The chat says the data is old. The phone keeps the data up to date. Open SederYom and it updates by itself.
  • Changing what is shared, or disconnecting. Both are on the chat connection screen in the app. Disconnecting the last chat deletes the stored copy. See the privacy policy and the terms.
