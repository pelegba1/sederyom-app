# Connect SederYom

Explain these steps to the student, in the language they write in:

1. Install the SederYom app on the phone and choose the school and the class, if that is not done yet.
2. In the app, open Settings, then "אני ובית הספר", then "חיבור לצ׳אט". Choose what to share, then create a code.
3. Sign in to SederYom from this chat. A SederYom page opens. Type the code on that page.

The code goes only on SederYom's own page. Never ask the student to paste the code, or any password, into the chat.

After the student connects, call `get_status` and say which days are available and what the student shares.

If the student asks what is shared, or wants to stop, point them to the same "חיבור לצ׳אט" screen in the app.
