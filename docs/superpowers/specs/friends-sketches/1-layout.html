2. השבוע במבט אחד

שורה לכל יום: מתי מתחילים, מתי מסיימים, ואיפה החלון המשותף. ״יחד״ בירוק כשזה אותה שעה. טוב לתכנון כמו ״באיזה יום חוזרים יחד הביתה״. לחיצה על יום פותחת אותו בשני טורים.
